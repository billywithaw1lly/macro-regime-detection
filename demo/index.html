Macro Regime Lab

Unsupervised regime detection on 15 macro indicators → 45 engineered time-series features → K-Means & Gaussian Mixture → regime-transition forecasting → asset-class returns by regime. Everything runs in your browser.

Data is a simulated 1990–2025 monthly panel from a hidden 4-state Markov regime process (true regimes are never shown to the models). Swap gen() for real FRED / Yahoo data to use it on history.
